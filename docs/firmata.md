# Arduino / Firmata

На macOS откройте **Devices → Arduino / Firmata…**. Адаптер работает с USB-последовательным интерфейсом платы, на которой уже запущен StandardFirmata. Введите точный путь вида `/dev/cu.…` и нажмите **Connect**. Соединение использует 57600 baud, 8N1. Панель запрашивает версию протокола, режимы каждого пина и карту аналоговых каналов. Поддерживаются сообщения протокола Firmata 2.5 и новее в ветке 2.x. [Протокол Firmata](https://github.com/firmata/protocol/blob/master/protocol.md), [исходник StandardFirmata](https://github.com/firmata/arduino/blob/main/examples/StandardFirmata/StandardFirmata.ino).

## Ввод

Выберите один из доступных **Analog A…** или **Digital D…**. Для просмотра выберите **Monitor only**. Для управления выберите поверхность и параметр, затем нажмите **Start Input**. Панель показывает полученное целое значение и его максимум. Аналоговый максимум определяется объявленной точностью ADC, цифровой вход передаёт 0 или 1. ApertureCue переводит этот диапазон в рабочий диапазон параметра через обычный путь управления редактора. Доступны opacity, brightness, gamma, red, green и blue.

**Stop Input** отключает текущую подписку. В каждый момент работает одна подписка. Закрытие окна, переход в другой проект, разрыв порта и обнаруженная перезагрузка завершают текущую привязку. После перезагрузки окно заново читает возможности платы. Для возобновления управления нажмите **Start Input**.

## Цифровой выход

Выберите цифровой пин, доступный для вывода, и уровень **LOW** или **HIGH**, затем нажмите **Write Pin**. Панель показывает состояние, которое сообщила прошивка. Для каждой команды используется запись одного пина, поэтому состояние остальных пинов того же порта не затрагивается. Активный вход нельзя одновременно использовать как выход.

При первом запросе адаптер переводит выбранный пин в режим цифрового вывода, затем устанавливает заданный уровень. Переключение режима может кратковременно установить LOW. Закрытие панели прекращает управление. Текущее состояние вывода платы при этом определяется прошивкой и её питанием.

Приложение подключается только к введённому порту и хранит привязку в текущем сеансе окна. В сборку не входят прошивка Arduino, USB-драйвер и SDK. Панель работает с аналоговым и цифровым вводом и цифровым HIGH/LOW. PWM, servo и периферийные шины остаются за пределами этого интерфейса.

## Проверка

```sh
dist/ApertureCue.app/Contents/MacOS/ApertureCue --firmata-test
```

Нативный сценарий подключает адаптер к самостоятельно созданному псевдотерминалу macOS. Вторая сторона посылает оригинальные тестовые сообщения и проверяет точные байты, которые записало приложение. Сценарий проверяет обнаружение, нормализованный ввод в реальный редактор, адресную запись и ответ прошивки, перезагрузку, обрыв и явное переподключение. Отчёт сохраняется в `artifacts/local/firmata-test/results.json`.

Проверка конкретной платы, версии прошивки, USB-моста и электрических уровней остаётся отдельной аппаратной задачей.
