# Textured stroke GUI verification

27 October 2026, Apple M2 / macOS 26.6.2. Agent-driven native GUI via CUA, with independently signed test copy `org.aperturecue.stroke-check`; only bundle identity/name changed. Opened a system-temporary copy of the original Strokes demo. No existing user project or reference installation was edited.

1. Open the procedural schema-4 example. A checker-textured four-node polyline and gradient-textured cubic appear inside their separate cages, with round ends and centerline guides.
2. Select **Edit path points** on the polyline. Drag its first anchor from screen `(694,692)` to `(730,650)`; the endpoint and texture move while its cage stays fixed. Toolbar **Undo** restores the endpoint; **Redo** returns the edited endpoint.
3. Select the cubic. Independent incoming/outgoing tangent guides appear. Drag the first outgoing handle from `(1056,859)` to `(1200,920)`; the curve bends visibly. **Path nodes…** shows the resulting local outgoing coordinate approximately `(0.38742850, 0.16454654)`.
4. **Insert after** splits the first cubic segment. Reopen the dialog; its first outgoing handle has the split coordinate. Set width `0.12`, enable **Closed path**, **Save node**: a thinner closed textured ribbon and three node sets appear. The accepted nearest-segment UV seam is visible at the closure/crossing. Undo this property edit to return to the open width-0.16 curve while retaining the inserted node.
5. **Input region** shows the complete rectangular gradient source, independently from stroke clipping. Return to Output, capture a scene, save, quit normally, launch a fresh process and Open the saved file. Both changed paths reappear. File assertions confirm schema 4, two surfaces, three cubic nodes, open curve, changed first line anchor and three scenes. Quit normally.
