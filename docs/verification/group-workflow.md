# Hierarchical group GUI verification

26–27 October 2026, Apple M2 / macOS 26.6.2. Agent-driven native GUI observations through CUA, using separately signed copies of the production app. Only test bundle identifiers/names changed. Original procedural documents were created in ignored build/system temporary folders; no existing user project or reference application was edited.

1. Create **Stage GUI** through the group dialog and assign the first checker surface. Create **Panel GUI** as its child, assign the checker to it, then assign the second gradient surface to Stage through the inspector parent picker.
2. Transform Stage through its dialog: translation `(0.04, 0.02)`, scale `(0.85, 0.9)`, clockwise rotation `12°` around `(0.49, 0.48)` on the 16:9 editor canvas. Both layers move together. Toolbar Undo restores the earlier composition; Redo returns the transformed composition.
3. Drag the checker's first world-space handle and capture another scene. Save the original test document. Its schema-3 data contains the local edited corner and nested UUID membership; source coordinates remain unchanged.
4. Dissolving the child initially exposed a preview defect: the checker became black beneath a correct outline. A separate clean output still rendered the checker, and exposing the editor restored it. CPU geometry and production offscreen GPU checks independently retained the checker pixels. Explicit transparent raster backing/clearing did not reliably solve this after Redo, so those attempts were not accepted as a fix.
5. Replace AppKit raster overlay drawing with transparent Core Animation vector paths/text above Metal. In a separate test process, reopen an original nested fixture derived from step 3, then use **Dissolve → Undo → Redo**. Both checker and gradient remain visible without opening an output or forcing an expose. The first vector pass also exposed a second vertical flip in contour coordinates; the correction uses the backing view's y-down coordinates directly. An asymmetric-cage assertion checks this mapping in the production editor suite.

6. In the final corrected-vector build, reopen the nested fixture. All four cyan handles and the outline match the asymmetric checker edges. **Dissolve → Undo → Redo** again keeps the complete checker and gradient visible after each action. Undo once more, save the nested state, quit normally, start a fresh process and Open the saved file. The nested parent picker, both layers and their aligned contours reappear. Quit normally. These GUI observations are separate from the automated reports and do not establish external projector, lighting, MIDI or camera hardware compatibility. GUI FPS labels and elapsed host availability are not performance/soak measurements.

The automated editor report covers create/assign/transform/reparent/dissolve, cycle rejection, inverse output/mesh dragging, unchanged source UV/mask, group visibility, shared scene references, opacity-track dissolution guard, output/lighting flattening and schema-3 save/new/open. The production GPU report separately checks affine/mirror/crop against a CPU oracle, transformed mesh barycentric interpolation, inherited opacity/visibility/non-isolated blending and exact before/after-Dissolve pixels for the GUI-derived checker fixture.
