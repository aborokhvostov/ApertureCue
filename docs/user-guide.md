# Руководство пользователя ApertureCue 0.1

Это ранняя настольная сборка для macOS 13+. Руководство описывает опубликованную [alpha 16](https://github.com/aborokhvostov/ApertureCue/releases/tag/v0.1.0-alpha.16) с форматом проекта schema 13. Точное состояние сборки и проверок находится в [status.md](status.md). Описанные операции не означают полного покрытия MadMapper 6.

## Запуск и демонстрационный проект

Готовая Apple Silicon сборка доступна в ZIP на странице alpha 16. Распакуйте весь архив, откройте **ApertureCue.app**, затем **File → Open** и `Media/Media.aperturecue.json` для новых source controls или `Demo/Composition.aperturecue.json` для геометрии и материалов. Папки demo и медиа держите вместе с их проектами. Сборка подписана ad hoc, без notarization.

Из корня исходников выполните `./scripts/build.sh`, затем `open dist/ApertureCue.app`. Приложение стартует с двумя процедурными поверхностями и двумя сохранёнными вариантами геометрии. Для собственного демонстрационного изображения и видео выполните:

```sh
dist/ApertureCue.app/Contents/MacOS/ApertureCue --generate-demo examples/Demo
dist/ApertureCue.app/Contents/MacOS/ApertureCue examples/Demo/Demo.aperturecue.json
```

Генератор также создаёт `Composition.aperturecue.json` — полностью процедурный пример schema 12 без внешних ресурсов. Откройте его через File → Open, нажмите Play для анимации материала и выбирайте слои 02/03/04 для Bezier warp, Group composition/Scoped masks и Key/FX. Два logical outputs A/B показывают разное содержимое в preview; реальные дисплеи не назначаются. Для сравнения выберите сцены Original spectrum/Alternate layer FX и GO.

Генератор создаёт `calibration.png` 960×540, `motion.mov` H.264 640×360, 30 fps, 3 секунды и `Demo.aperturecue.json`. Это собственные тестовые материалы. При повторном запуске генератора существующий `motion.mov` не заменяется; для независимого опыта выберите новую папку.

## Источники и папки кадров в schema 13

В секции MEDIA нажмите **Sources…**, выберите источник и **Assign to selected surface**. Затем доступны **Play source**, **Pause source**, **Seek source** и **Follow master**. Первые три переключают только этот источник на независимые часы; остальные поверхности и master не перематываются. Follow master возвращает источник к шоу. Состояние транспорта временное, настройки сохраняются.

В Sources задайте Mode, signed speed, Trim In/Out и **Save source settings**. Пустой Out означает длительность файла. Once удерживает последний кадр; для повторного запуска выполните Seek source = 0 и Play source. Loop повторяет; Hold и скорость 0 фиксируют начальный кадр; PingPong движется туда и обратно; отрицательная скорость начинает с конца диапазона. Random использует сохранённый seed/interval, поэтому повторный seek воспроизводим. Source elapsed и item time отличаются из-за скорости, trim и циклов. Обычная кнопка Loop согласована с сохранённым режимом.

**Import image sequence…** выбирает папку, фиксирует естественно отсортированные имена файлов и назначает источник выбранной поверхности. Числовые пропуски проигрываются подряд; FPS меняется в Sources. Добавленные файлы появятся только после **Refresh sequence manifest**. Отсутствующий или повреждённый кадр показывает fallback и диагностику; Refresh/relink повторяет загрузку. Collect переносит точно сохранённый список кадров. Символьные ссылки кадров не принимаются.

## Аудио и восстановление в schema 13

Import также принимает аудиофайлы. **Audio routing…** задаёт устройство, число входных/выходных каналов и матрицу: строка — выход, столбец — вход. Например, stereo swap: `0, 1, 1, 0`. Нативная матрица поддерживает до 8 каналов; проверены собственные WAV/MOV PCM fixtures. Громкость — master после матричного clipping. Mute сохраняется с маршрутом; потеря выбранного устройства оставляет тишину и требует повторного Save route. **Use ordinary system audio** убирает явную матрицу. При custom playback используется PCM backend с автоматической матрицей, если явной нет. Reverse/Random/Hold audio беззвучны; forward 0.125…8 меняет высоту вместе со скоростью. Физические каналы и слышимая синхронизация отдельно не подтверждены.

Оригинальный `Media/Media.aperturecue.json` показывает папку кадров, обычное H.264 и reverse ping-pong. Его стереотон не назначен и имеет volume 0. Для прослушивания назначьте источник и выберите громкость/маршрут. Генератор `--generate-media-demo` требует новую папку и не перезаписывает существующие проекты.

Recovery привязан к точным байтам и пути сохранённого файла. Устаревший, повреждённый или старый несвязанный sidecar остаётся на месте с диагностикой и не предлагается как актуальное восстановление. Save удаляет только собственный checkpoint; явный Discard удаляет собственный recovery, чтобы отброшенные правки не возвращались при открытии. Ошибки autosave видны в status.

## Медиа и поверхности

**Import…** или File → Import Media… (`⌘I`) открывает выбор изображений, видео и аудио. При импорте источник назначается выбранной поверхности; если поверхности нет, создаётся новая. Для повторного назначения выберите media слева, затем surface и нажмите **Assign to surface**.

**+ Quad**, **Duplicate**, **Delete** изменяют список поверхностей. Список подписан `back → front`: последующие строки рисуются поверх предыдущих. Кнопки со стрелками меняют порядок. Это собственное соглашение ApertureCue; оно отличается от списка слоёв функционального референса.

В режиме **Output geometry** перетаскивайте четыре угла выбранного quad. Вершины не должны пересекаться или схлопываться. **Shift** включает привязку к сетке 5% canvas. В **Input region** отображается исходное медиа и отдельно редактируется его область выборки. Изменение input не меняет output. Геометрия хранится в нормализованных координатах; изменение размера окна не перемещает поверхность в проекте.

**Reset quad / input** сбрасывает текущую сторону и выключает Link. Сброс output выпрямляет его сетку, сохраняя независимые source UV; сброс input возвращает полный источник и убирает его source lattice. Перенос углов рамки преобразует соответствующую mesh/warp вместе с рамкой; независимая входная сторона сохраняется, если Mesh link выключен. **Create 4 × 4 warp mesh** создаёт регулярную сетку. **Edit mesh points / Edit quad corners** переключает редактируемые handle points. Это регулярная линейная warp-сетка. Для гладкой деформации используйте отдельные Bézier controls, описанные ниже. Узлы текстурного пути редактируются отдельно.

Чтобы закрепить настройку, выделите поверхность и нажмите **Lock geometry** в правой панели. Строка слоя получает отметку **Locked**, контур остаётся доступен для выбора, а ручки исчезают. Блокируются правки рамки, формы, входной области, warp mesh, polygon mask и узлов и ширины пути. Сцены по-прежнему могут менять геометрию, а групповые команды, назначение медиа, цвет и автоматизация остаются доступны. **Unlock geometry** возвращает ручки и команды. Оба действия поддерживают Undo/Redo. Блокировка сохраняется в проекте. Новый дубликат и слой, возвращённый сценой после удаления, открываются для редактирования. Undo удаления возвращает прежнюю блокировку.

### Triangle и Ellipse

Кнопки **+ Triangle** и **+ Ellipse** создают поверхности. **Shape · four-corner frame** меняет форму выбранного слоя с Undo/Redo. Для треугольника нажмите **Edit triangle vertices** и перетащите любую из трёх ручек внутри рамки. При выходе за рамку или схлопывании треугольника вершина остаётся в последнем допустимом положении. **Edit cage corners** возвращает четыре угла перспективной рамки. **Reset triangle vertices** восстанавливает исходный контур, сохраняя рамку, сетку и входную область. Правки вершин и сброс поддерживают Undo/Redo.

Вершины задают видимый контур внутри рамки. Для кадрирования изображения используйте **Input region**. Если сетка сложена и несколько её треугольников лежат под курсором, редактор берёт первый найденный участок. Эллипс задаётся вписанной окружностью. Пропорции рамки, перспектива и сетка деформируют обе формы вместе с изображением.

Контур формы и **Edge feather** вычисляются в local области, отдельно от crop и polygon mask источника. Антиалиасинг охватывает примерно один пиксель границы; feather задан в нормализованных local единицах, а не миллиметрах/пикселях проектора. **Input region** всегда показывает полный источник. Пустые углы формы пропускают выбор к нижнему видимому слою; прозрачность пикселей изображения и source mask не меняют геометрические границы выбора. При переходе сцены shape переключается дискретно в середине. `Demo/Shapes.aperturecue.json` — самостоятельный процедурный пример обеих форм.

### Line и Bézier

**+ Line** создаёт открытую текстурную линию; **+ Bézier** — кубическую кривую с двумя узлами. Их форма находится внутри обычной перспективной рамки. В **Edit path points** перетаскивайте узлы, а у Bézier — независимые ручки `i` (incoming) и `o` (outgoing). Перенос узла на canvas сдвигает обе его ручки в мировых координатах. **Edit cage corners**, **Input region** и **Edit mesh points** переключают другие, независимые стороны редактирования. При сложенной warp-сетке обратное редактирование выбирает первый покрывающий треугольник: перекрывающиеся части неоднозначны.

**Path nodes…** открывает точные local координаты узла/касательных. Выберите узел, введите значения и нажмите **Save node**; свойства одного узла сохраняются за раз. **Insert after** делит его следующий сегмент пополам, сохраняя кубическую кривую (у последнего узла открытого пути делится предыдущий сегмент). **Remove node** соединяет соседей с оставшимися ручками. Минимум два узла для открытого пути, три для **Closed path**, максимум 32. Замыкание, ширина, вставка, удаление и перетаскивание поддерживают Undo/Redo. Невалидная форма или исчерпанный бюджет точности отклоняются целиком. Переключение Line/Bézier сохраняет узлы и касательные; Line временно игнорирует касательные.

**Stroke width** — полная толщина в долях высоты local рамки при метрике 16:9; численно разрешены 0.001…1. Группа, перспектива и mesh деформируют полосу вместе с рамкой, поэтому это не постоянная ширина в пикселях проектора. Точки и ручки лежат в local `[0,1]²`; полоса, круглые концы и круглые стыки обрезаются границей рамки. Оставляйте запас вокруг пути, если нужны целые концы.

Текстура растягивается один раз вдоль суммарной длины пути; поперечная координата идёт от одной стороны к другой. **Input region** задаёт независимый crop этой текстуры, а polygon mask ограничивает получившиеся source UV. При пересечениях выбирается ближайший сегмент, при точном равенстве — первый. Alpha применяется один раз к объединению полос; UV могут иметь шов на пересечениях/резких поворотах и в месте замыкания. **Edge feather** смягчает край полосы в local единицах.

Кубические сегменты адаптивно разбиваются с local допуском 0.0005, максимум 256 линейных сегментов и глубина 10. Это не гарантия ошибки менее пикселя после сильной перспективы/увеличения. Готовые сегменты кешируются до изменения пути; стоимость GPU зависит от их количества. Для свободного рисования есть отдельная команда **Draw freehand line**. Выбор иных caps/joins и filled FreeDraw shapes пока не реализован. `Demo/Strokes.aperturecue.json` показывает собственные line/curve примеры. В сценах совместимые пути интерполируются по точкам/касательным/ширине; несовместимые или схлопывающиеся пути переключаются в середине перехода.

## Точные преобразования, Bézier warp и свободный рисунок

**Transform surface…** в правом инспекторе применяет перенос, scale и поворот выбранной поверхности. Порядок — scale → rotation → translation; pivot задаётся в мировых нормализованных координатах. Отрицательный scale отражает. Source crop и независимая входная сетка сохраняются. Чтобы сдвигать стрелками, сначала нажмите на холст: шаг 0.001 по соответствующей оси, с **Shift** — 0.01. В **Input region** стрелки двигают входную область; в **Output geometry** — выходную геометрию. Блокировка геометрии запрещает эти команды.

Для гладкой деформации выберите **Bezier warp…**, задайте 1…8 patch columns/rows и нажмите **Create warp**. Эта операция заменяет регулярную сетку вместе с её source edits; исходная перспективная рамка и quad crop сохраняются. **Edit output Bezier controls** показывает независимые точки решётки на выходном холсте. **Edit input Bezier controls** создаёт независимую source lattice и показывает её над полным источником. Перетаскивайте выбранную точку; остальные точки не перемещаются. Геометрия отклоняет изменения, превышающие бюджет точности, и оставляет последнее допустимое состояние.

В **Bezier warp…** уже созданной решётки выберите **Space** и **Control row/column**, введите x/y и нажмите **Save point**. Output координаты мировые, input — source UV. **Edit on canvas** переключает к ручкам; **Reset warp** убирает обе Bézier lattices и возвращает quad crop/рамку. Один drag или числовой Save — одна операция Undo/Redo.

**Mesh link: OFF/ON** явно включает связь соответствующих source/output точек для регулярной или Bézier mesh. Создайте mesh до включения связи. При включении после разных правок текущие точки сохраняются; синхронизируются последующие движения соответствующей точки. В выключенном режиме source и output редактируются независимо. Для перспективных рамок перенос связанной точки пересчитывается через рамки, поэтому это не одинаковая числовая delta в двух пространствах.

**Draw freehand line** начинает новый открытый текстурный путь. Нажмите и ведите мышью по холсту, отпустите для создания; **Escape** отменяет захват. Путь становится обычной Line surface с редактируемыми узлами, media assignment и Undo/Redo. Допустимы до 512 samples и результат до 32 узлов; слишком сложный рисунок отклоняется вместо скрытого ухудшения точности. Это контур-полоса с круглыми caps/joins, не залитая фигура и не распознавание рисунка.

## Цвет, маски и группы

### Materials, ISF и Key / FX

Кнопки второй верхней строки действуют на выбранную поверхность. Начать можно с **Materials… → New material**: задайте имя, оставьте **Inputs JSON** равным `[]` и **Selected surface parameter values JSON** равным `{}`, затем введите выражение, например:

```text
vec4(uv.x, uv.y, 0.5+0.5*sin(time), 1)
```

**Save + Assign** сохраняет материал в общей библиотеке и назначает поверхности. Выберите **Play**, чтобы двигалось время `time`; при Pause оно стоит. `uv` — конечные source coordinates с началом сверху слева, `size` — размер render target, `sample(uv)` читает исходное изображение/видео или generator. Например, `sample(uv) * vec4(1,0.5,0.5,1)` ослабляет зелёный и синий каналы источника.

Для регулируемого параметра задайте выражение `mix(sample(uv),vec4(1,0,0,1),amount)` и такой **Inputs JSON**:

```json
[{"name":"amount","label":"Tint amount","kind":"float","defaultValue":[0.25],"minimum":[0],"maximum":[1]}]
```

**Selected surface parameter values JSON** `{"amount":[0.75]}` задаёт значение только выбранному слою; `{}` использует defaults. Допустимы float, bool (числа 0/1), point2D и color (массивы из 1, 1, 2 и 4 значений соответственно), до 16 входов. Выражение — ограниченная RGBA-математика до 4096 UTF-8 bytes, а не произвольный GLSL/Metal. Loops, includes и пользовательские функции не принимаются. Ошибка синтаксиса, параметров или компиляции сохраняет документ и последний принятый материал; исправьте текст и повторите Save.

Для переиспользования выберите материал из списка и нажмите **Save + Assign**. **Clear selected material** снимает только текущее назначение. **Delete** удаляет определение и его ссылки из текущих слоёв и сохранённых сцен; Undo восстанавливает их. Изменение общего определения затрагивает все его назначения. Если новый интерфейс несовместим с overrides любого слоя/сцены, сохранение отклоняется.

**Import ISF…** принимает выбранный UTF-8 `.fs` до 64 KiB. Для первого опыта используйте собственные `examples/Materials/OriginalGradient.fs` и `OriginalTint.fs`. Поддерживается ISF 2 с одним выражением `gl_FragColor`, typed inputs, одним image input, `TIME`, `RENDERSIZE` и normalized image sampling. ISF coordinates сохраняют начало снизу слева. Multipass, persistent buffers, внешние изображения, audio/event/long inputs, custom functions и другие shader statements отклоняются. Полный список и provenance — в [material spec](material-spec.md). Поле Credit сохраняет атрибуцию; оно само по себе не даёт права распространять импортированный чужой материал.

**Key / FX…** открывает отдельные настройки выбранного слоя. Для зелёного фона выберите `chroma`, Key RGB `0 / 1 / 0`, затем подберите Threshold/Softness; Spill уменьшает избыток доминирующего канала key. `luma` использует яркость вместо RGB distance. Saturation 0 обесцвечивает, 1 сохраняет исходные цвета, 2 усиливает; Invert меняет RGB; Posterize 0 отключает эффект, 2…256 задаёт число уровней. **Save FX** применяет, **Reset FX** возвращает defaults. Key/FX выполняются перед surface color/brightness/gamma; geometry lock не блокирует эффекты.

### Дополнительные маски слоя, группы и всей композиции

Нажмите **Scoped masks…** и выберите Scope: Selected layer, доступную Group или Global composition. В каждом scope допускается до восьми дополнительных масок. **New mask** создаёт inset polygon; **Bézier contour** для новой маски начинает с ellipse. Задайте имя, Enabled, Invert и Feather. Координаты **Source UV / group local** означают UV слоя либо локальную рамку группы; **Output canvas** остаются на общем холсте. Global использует только Output canvas. Несколько масок перемножают alpha; добавленная inverted mask вырезает отверстие внутри предыдущей.

**Save mask** сохраняет свойства. **Nodes…** сначала сохраняет эти свойства, затем открывает числовой редактор. Выберите узел и задайте Anchor x/y; для кубической маски отдельно доступны абсолютные Incoming/Outgoing tangent x/y. **Save node** сохраняет одну точку с ручками. **Insert after** делит выбранное замкнутое ребро, включая последнее→первое; кубическая subdivision сохраняет кривую. **Remove node** соединяет оставшихся соседей и меняет контур. Диапазон 3…128 узлов. **Delete mask** убирает выбранную дополнительную маску; исходная polygon mask инспектора остаётся отдельной.

Превращение polygon в Bézier сохраняет прямые рёбра с нулевыми ручками. Превращение Bézier в polygon соединяет его anchors и меняет кривую. Feather задан в долях выбранного пространства; это не измеренная ширина на проекторе. Layer geometry lock запрещает редактирование дополнительных масок слоя; групповые и глобальные операции действуют отдельно. Каждая Save/Insert/Remove/Delete имеет собственный Undo.

Inspector содержит opacity, brightness, gamma, RGB multiplier и режимы normal/add/multiply/screen. **Generator / fallback** выбирает checker, gradient, solid или grid и снимает назначение медиа. Если назначенный ресурс не загрузился, procedural fallback позволяет продолжить настройку; ошибка отображается в нижней строке.

**Add polygon mask** создаёт четырёхточечную маску выбранной поверхности; **Edit polygon mask** включает ручки, **Remove mask** убирает её. В блоке **Polygon mask · this layer** выберите **Source UV coordinates** (маска движется вместе с текстурой и её crop) или **Output canvas coordinates** (контур остаётся на выходном холсте при движении поверхности, mesh и группы). Переключение переиспользует те же числа координат; автоматического пересчёта нет. Редактор открывает нужный вид: источник или выходную композицию. Для выхода из редактирования маски выберите **Output geometry** / **Input region** сверху.

**Mask vertices…** открывает точный редактор вершин. Выберите **Vertex**, введите x/y и нажмите **Save vertex**. **Insert after** добавляет середину следующего ребра без изменения контура; после последней вершины делится замыкающее ребро к первой. **Remove vertex** удаляет выбранную точку и соединяет соседние. Допустимо 3…128 вершин; для очистки всей маски используйте **Remove mask**. Каждая операция поддерживает Undo/Redo. Номера точек видны на холсте в режиме редактирования маски. Координаты относятся к выбранному пространству; 0…1 покрывает его целиком, допустимы конечные значения вне этого интервала.

**Invert mask: ON** вырезает внутреннюю часть контура и показывает нижние слои. **Mask feather** смягчает край сохраняемой части; ширина 0…0.5 задана в нормализованных координатах выбранного пространства. При 0 край жёсткий. **Edge feather** отдельно смягчает край самой поверхности. Пустая маска пропускает весь слой даже при включённой инверсии. Маска действует только на свой слой, в том числе при маршрутизации на несколько выходов; соседние слои не меняются. Блокировка геометрии блокирует все настройки маски.

Сцены сохраняют контур, пространство, инверсию и feather одним полем **Mask**. При смене пространства или инверсии вся маска переключается в середине перехода. Старые проекты сохраняют прежнюю source-UV маску. В schema 12 несколько дополнительных polygon/Bézier masks, group/global scope редактируются через **Scoped masks…**; описанный блок инспектора остаётся отдельной исходной маской слоя. Для открытия старой сборкой сохраняйте исходный файл отдельно через Save As. [Поведение исходной маски](polygon-mask-spec.md).

### Иерархические группы

В **Parent group** выберите существующую группу или Root. Назначение сохраняет мировую геометрию output/mesh; input и source mask остаются прежними. Прозрачность и видимость начинают наследоваться от нового родителя.

**Groups…** / **Group controls…** открывает редактор групп. Выберите **New group**, задайте имя и Parent, opacity 0…1 и видимость. Чтобы включить выбранную поверхность в новую группу, отметьте **Assign selected surface**, затем **Save group**. Для существующей группы сохранение нового Parent сохраняет мировую геометрию всего поддерева. Циклы запрещены. Меню показывает путь и часть UUID, поэтому имя не служит идентификатором.

Для выбранной группы нажмите **Transform…**. Задайте перенос в нормализованных координатах canvas, ненулевой Scale X/Y и угол по часовой стрелке. Отрицательный масштаб отражает. Pivot задан в мировых координатах; по умолчанию это центр рамок/mesh всех текущих потомков. Порядок: scale → rotation → translation. Угол учитывает пропорции редакторского canvas 16:9; другой aspect выходного дисплея меняет его видимое направление. Каждый Apply — относительная операция с единым Undo/Redo, локальные точки потомков сохраняются. Вложенные rotation/nonuniform scale могут давать shear, который сохраняется точно в affine-матрице.

**Toggle entire group** меняет собственную видимость группы, сохраняя индивидуальные enabled-флаги поверхностей. В обычной группе opacity применяется к каждому потомку после surface automation. **Group composition…** включает изолированную композицию: сначала группа собирается в прозрачный буфер, затем её opacity применяется один раз. Здесь же задаются групповые normal/add/multiply/screen и Key/FX. Групповые маски, FX или ненормальный blend также включают буфер композиции, даже без флажка Isolated. Включённые потомки должны идти подряд в порядке слоёв: неоднозначное перемежение с посторонним слоем отклоняется, слои автоматически не переставляются. Определения групп общие; отдельной групповой automation пока нет.

**Group perspective…** предлагает четыре пары мировых x/y: верхний левый, верхний правый, нижний правый и нижний левый углы. Команда переводит текущую общую ограничивающую рамку группы в выпуклый четырёхугольник. Локальная геометрия и source crop потомков сохраняются. Групповое преобразование действует также на geometry-locked потомков. Singular matrix, пересечение горизонта и невалидные углы отклоняются целиком; Undo отменяет одно Apply.

Перед **Dissolve** сбросьте групповую isolation, blend, FX и masks: их запекание в дочерние слои не поддерживается. **Dissolve** удаляет определение обычной группы, переносит прямых потомков к её родителю и запекает её affine/opacity/visibility в их состояние. Поверхности, media и ссылки в сценах сохраняются; Undo возвращает всю иерархию. Если opacity группы не равен 1 и на прямом surface target есть opacity track, операция отклоняется: иначе track перекрыл бы запечённый множитель. Удалите соответствующий track или осознанно измените group opacity перед Dissolve.

Сцены сохраняют surface membership/локальную геометрию, но используют **текущие общие определения групп**. Поза группы не входит в surface snapshot. При переходе между разными parent frames membership/output/mesh переключаются вместе в середине перехода; source crop и совместимые числовые параметры могут интерполироваться. Редактирование или Undo во время перехода фиксирует промежуточное состояние как отменяемую команду, включая нажатие ручки без перемещения.

`Demo/Groups.aperturecue.json` — собственный процедурный пример вложенной группы с перспективными примитивами.


## SVG и статический импорт OBJ

### SVG как самостоятельный источник

Кнопка **SVG…** во второй верхней строке импортирует выбранный SVG как собственную постоянную PNG-копию. Она назначается выбранной поверхности; если выбора нет, создаётся новый слой. После импорта PNG ведёт себя как обычный image asset: Input crop, warps, masks, materials, Save/Open и Collect работают с ним. Исходный SVG больше не нужен для отображения; редактирования векторных узлов после импорта нет. Undo убирает назначение/asset из документа, сохраняя PNG для Redo.

Поддерживаются viewBox, g, path с M/L/H/V/C/Q/Z, rect, circle/ellipse, line/polyline/polygon, affine transforms, простые fill/stroke, fill rules и opacity. По умолчанию длинная сторона PNG — 1024 pixels; aspect берётся из viewBox. CSS/style, text, image/use, gradients, arcs, DTD/external entities и неизвестные атрибуты отклоняются с диагностикой. Для stroked paths допускается uniform transform; ограничения и размеры — в [SVG spec](svg-import-spec.md). Для пробы используйте собственный `examples/SVG/geometry.svg`.

### Projected OBJ

File → **Import projected OBJ…** читает polygonal Wavefront OBJ и предлагает camera Z и vertical FOV. Камера смотрит на origin; видимый результат запекается в редактируемые 2D patches, по три quad на каждый triangle. Выбранное media назначается импортированным patches, а OBJ texture V переводится из нижнего левого начала в верхнее левое.

Импорт поддерживает positive/negative indices и planar polygons, но не загружает MTL, внешние textures или исходную 3D-сцену. Чтение/разбор/проекция выполняются в фоне; результат не добавляется в другой документ, если во время работы был выполнен New/Open. UV-degenerate и неподдерживаемая геометрия отклоняются с диагностикой. Static projection ограничена 1365 triangles; ввод — 16 MiB. Triangles сортируются по средней глубине; пересечения не разрешаются depth buffer. Triangle, пересекающий near/far clipping plane, пропускается целиком. Это полезный static mapping path, но не полноценный 3D renderer, calibration или scanner.

## Воспроизведение

**Play/Pause**, **Stop** и основной slider управляют master show clock и источниками в режиме Follow master. Stop ставит их на паузу и переводит к началу. Seek в pause обновляет кадр, сохраняя pause. Независимые источники продолжают использовать свои часы; управляйте ими через **Sources…** и при необходимости нажмите **Follow master**. В media inspector доступны **Loop ON/OFF**, volume, **Source playback / routing…** и **Relink media…**.

Поддержку конкретного файла определяет AVFoundation установленной macOS. Наличие расширения `.mkv`, `.avi` или `.webm` в классификаторе не гарантирует decoder: при ошибке будет показана диагностика. Проверенный тестовый codec/container должен быть указан в status. Обычный AVPlayer воспроизводит встроенное аудио через системный вывод; явная Audio routing и custom playback используют PCM adapter, описанный выше. Физические многоканальные выходы, слышимая AV-синхронизация и frame sync нескольких плееров отдельно не подтверждены.

**Camera…** запрашивает доступ к камере только по действию пользователя и предлагает доступные устройства. Источник назначается выбранной поверхности. Capture backend сохраняет последний кадр, пропускает опоздавшие и выводит диагностику недоступного устройства. Работа без подключённой камеры и сама реализация adapter не подтверждают capture на конкретной модели; доступность/разрешение/отключение проверяются отдельно. Camera source остаётся live при pause movie transport.

## Управление шоу в schema 14

**Show → Conductor…** открывает банки, строки и ячейки. Создайте банк и строку,
затем **Capture timeline…** скопирует включённые дорожки текущего таймлайна.
При необходимости выберите захват только для выбранной поверхности. Для
выбранной ячейки **Launch** запускает собственные часы. Новая ячейка той же
строки заменяет предыдущую, другие строки продолжают работать. При конфликте
за параметр побеждает нижняя строка. Запуск из другого банка останавливает
ячейки предыдущего банка. **Stop row** и **Stop all** снимают их влияние.

**Signal → Add signal…** в Conductor создаёт sine, triangle, square либо
add/multiply из двух существующих сигналов. **Bindings…** связывает выход
с параметром выбранной поверхности и диапазоном значения. Сигналы
следуют master time и применяются перед активными строками Conductor.

Выберите форму перехода в **Scenes…**. Таймлайн поддерживает **Jump** с
позициями назначения и числом повторов 1–64. Jump срабатывает на прямом
пересечении, Seek не воспроизводит пропущенные события. **Retime key range…**
переносит или масштабирует время ключей выбранной дорожки одной операцией
Undo. Значения и типы интерполяции сохраняются.

- **Show → Schedule…** настраивает запуск сцен во время работы приложения.
  Включите **Arm schedule** после сохранения или импорта событий. Для
  явного запуска с включённым расписанием передайте путь проекта и
  `--arm-schedule` исполняемому файлу приложения. [Расписание и ICS](show-schedule-spec.md)
- **Show → OSC / MIDI Tracks and Clock…** позволяет привязать локальные OSC
  и виртуальные MIDI события к мастеру. Включение отправки и приёма внешних
  часов действует в текущем сеансе. Внешний источник управляет временем и на
  время подключения подавляет локальные Jump. [События и внешний таймкод](show-control-events-spec.md)

Для пробы откройте `Demo/ShowControl.aperturecue.json`, запустите ячейки
**Rise** и **Fall** в разных строках банка **Parallel tracks**. Чтобы увидеть
Jump и Pause, остановите ячейки и нажмите основной **Play**.

## Монтаж источников

Schema 14 добавляет в **Montage sources…** реверс, кроссфейд и аудио. Для
кроссфейда задайте **Incoming crossfade s**, равный полному перекрытию
с предыдущим клипом той же дорожки. Минусовая скорость доступна видео.
Звуковые файлы формируют отдельную дорожку, а **Play movie audio** включает
первую звуковую дорожку прямого видео. [Правила монтажа](montage-spec.md)

Следующее описание базового монтажа использует рабочий процесс alpha 9.


Импортируйте изображения и видео через **Import…**. В левой библиотеке нажмите **Montage sources…**, затем **New montage**. Задайте **Name**, **Duration s**, **Loop montage** и поведение пустого участка **Black / Skip**; нажмите **Create montage**. Монтаж появляется в общей библиотеке как назначаемый источник.

Выберите **New clip**, исходный файл в **Source asset**, **Start s** и **Duration s**. Для видео задайте **Video In s / Out s**, **Rate** (0.25…4) и при необходимости **Loop trimmed video**, затем **Add clip**. Изображению нужны только Start/Duration. Нажатие блока на полосе или строки таблицы выбирает клип; время редактируется числовыми полями и **Save clip**. **Delete clip** удаляет выбранный клип. Перекрытия отклоняются; следующий клип может начинаться точно в конце предыдущего. Для видео без clip loop длительность клипа не может превышать `(Out−In)/Rate`.

Изменения свойств монтажа сохраняет **Save montage properties**, правки клипа — **Save clip**. Несохранённые поля остаются draft при обычном обновлении окна. Каждая успешная операция имеет одну команду Undo/Redo. **Seek clip start** переводит общее время шоу к началу выбранного клипа; Play/Pause/Stop и основной slider управляют монтажами вместе с parameter timeline. Длительность графа в **Timeline…** определяет конец самого шоу; длительность монтажа задаёт его собственный конец/цикл.

Выберите поверхность в основном окне и нажмите **Assign montage to selected surface**. Также можно выбрать монтаж в общей библиотеке и нажать **Assign to surface**. Поверхности с одним montage UUID показывают один принятый кадр; разные монтажи одного видео имеют независимые позиции. **Black** выдаёт чёрный источник с обычными opacity/blend поверхности; **Skip** исключает её из композиции и показывает нижние слои. Загрузка, ошибка и отсутствие подходящего кадра используют тот же режим с диагностикой, без подстановки checker. Поворот из video metadata учитывается при чтении texture; surface input/mask остаются в координатах повёрнутого изображения.

Клипы монтажа воспроизводятся без звука. Обычный видеоисточник звучит только при прямом назначении на текущую поверхность; opacity/visibility/routing не отключают его звук. Монтаж не меняет volume или позицию такого обычного источника. Одновременно допускаются восемь активных видеомонтажей; девятый показывает выбранный gap и диагностику. Приоритет определяется UUID. Reverse, crossfade/перекрытия, аудиомонтаж, камеры/вложенные монтажи и запись клипов пока отсутствуют.

Сцены сохраняют UUID назначения, а определения монтажей общие для проекта. **Delete montage** очищает его назначения в текущих поверхностях и сохранённых сценах; Undo восстанавливает всё вместе. Save/Open/Recovery/Collect сохраняют определения и ссылки. `Demo/Montage.aperturecue.json` — собственный пример с изображением, видео, Black/Skip, trim/rate/loop. Schema 7 требует новый reader; alpha 1…8 такие проекты отклоняют. Сохраняйте отдельную копию для старой сборки.

## Выход на дисплей

Нажмите **Outputs…** и выберите существующий выход или **New output**. **Open preview window** показывает чистую композицию в отдельном окне рядом с редактором. Для полноэкранного показа выберите **Fullscreen display** и нажмите **Open fullscreen**. Предпросмотр и полноэкранное окно могут работать одновременно для одного выхода. **Escape** закрывает активное окно вывода. **Close outputs** закрывает все окна вывода. **Blackout** делает их чёрными и оставляет композицию видимой в редакторе.

В правой панели поверхности выберите **All outputs** либо конкретный выход. Это назначение сохраняется в сценах и при смене дисплея. Несколько разных выходов можно одновременно просматривать в отдельных окнах. Для полноэкранного показа на каждом дисплее используется один выход.

При открытии fullscreen сохраняется идентификатор дисплея macOS. Для старого проекта выберите дисплей заново. Если сохранённый дисплей отключён, неоднозначен или участвует в зеркалировании, полноэкранное окно закрывается после уведомления macOS. Привязка остаётся в проекте. Чтобы возобновить показ, откройте **Outputs…** и нажмите **Open fullscreen** после подключения либо выберите другой доступный дисплей. Сохранённые width/height остаются параметрами проекта, а полноэкранное окно занимает текущую рамку дисплея.

### Video wall и Edge blend

Выберите поверхность с источником, нажмите **Video wall…**, задайте Columns/Rows и **Create wall**. Например, 2×2 создаёт четыре новых logical outputs и четыре unit-quad clone с соответствующими source crops; исходный слой скрывается. Всё действие отменяется одним Undo. Медиа, material/FX, цвет и quad crop источника сохраняются, а group membership, shape, mesh/warps, masks и feather у tiles сбрасываются. Источник остаётся в документе; сохранённая ранее сцена может снова включить его.

При нулевых Bezel/Overlap tiles покрывают исходник без внутренних пропусков. **Bezel gaps x/y** пропускают заданную долю полного источника между экранами. **Projector overlap x/y** задаёт перекрытие как долю tile; bezel и overlap на одной оси одновременно не принимаются. Columns/Rows 1…16, максимум 64 tiles. Новые outputs не привязываются к физическим дисплеям автоматически: откройте **Outputs…** и назначьте каждый явно. Несколько preview windows позволяют проверить разные crops без проекторов.

**Edge blend…** редактирует выбранный logical output: Left/Right/Top/Bottom width — доли его площади, Power — форма ramp, Source gamma и Black lift — ручная цветовая коррекция. **Save output** обновляет его preview/fullscreen/feedback composition. Для пары соседних выходов используйте одинаковые overlap и power; программная complementary ramp не означает измеренного оптического шва на реальных проекторах. Blackout остаётся чёрным. [Численная модель](edge-blend-spec.md).

### Результат выхода как источник

Выберите слой, нажмите **Feedback…**, выберите logical output и **Save source**. Назначение заменяет media source этого слоя. **No output feedback** снимает назначение; для возврата изображения/видео назначьте его из библиотеки. Генератор снимает и media, и feedback assignment.

Источник читает последнее полностью завершённое поколение выходов. Все feedback routes используют одно предыдущее поколение; циклы между выходами и self-feedback получают явную задержку, без ожидания друг друга. Первый кадр и сброс истории чёрные. Это предыдущий завершённый render generation, а не обещание задержки ровно в один refresh физического дисплея.

Для первого опыта создайте Output A, поместите на него небольшой яркий слой и второй слой с feedback source A, уменьшите opacity feedback и слегка сдвиньте его рамку. Получится накопление предыдущих кадров. При цикле без нового видимого источника чёрная начальная история останется чёрной. История очищается при смене проекта, Stop/Seek/loop и переназначении feedback; textures не записываются в файл проекта. Допускаются до восьми referenced outputs, до 4096 pixels на ось и 16M pixels суммарно; удерживается максимум четыре поколения. При перегрузке новое поколение пропускается, а не создаётся неограниченная очередь. Геометрия/маски/material/FX feedback слоя остаются обычными параметрами.

## Снимки и управление шоу

В строке **SCENES** кнопка **Capture** сохраняет полный снимок текущих поверхностей с переходом 1 секунда; выберите его и нажмите **GO**. **Scenes…** открывает редактор полных снимков и selective cues. Оба режима сохраняют только surface state: определения групп, assets, fixtures, output configuration, timeline и transport не входят в снимок. Это более узкая область, чем полный проект Scene в документации референса.

### Создание и изменение Cue

Нажмите **New draft**, задайте **Name**, **Transition s** (0…86400) и **Follow s** (пусто — без продолжения; иначе 0…86400 секунд после конца перехода). Выберите поверхность в **SURFACE FIELDS**, отметьте нужные поля и повторите для других поверхностей. **All fields on surface**, **Clear surface** и **Clear all fields** меняют draft. **Capture selective** создаёт новый Cue с текущими значениями отмеченных полей; нужен хотя бы один target и одно поле. **Capture full** всегда создаёт новый снимок всех текущих поверхностей и их порядка.

У сохранённого Cue scope фиксирован. Для другого scope создайте новый Capture. **Save cue properties / fields** сохраняет имя, timing и выбор полей, оставляя захваченные значения прежними. Включение другого поля уже сохранённой поверхности использует его значение из сохранённого snapshot; Save не читает текущий inspector. При снятии всех полей поверхность исключается из этого Cue. Строки сохранённого Cue ограничены его snapshot: для других текущих поверхностей используйте **New draft**. **Recapture values** явно заменяет захваченные значения текущими для выбранных targets/полей, сохраняя имя и timing. Если изменены имя или timing, сначала сохраните их отдельной кнопкой. **Stored snapshot** и **Current surface** помогают сравнить значения; длинный текст доступен в tooltip. **GO selected** вызывает сохранённый Cue и его сохранённую маску, а не несохранённый draft.

### Поля selective Cue

Каждый target привязан по UUID. Поля ниже — атомарные единицы: связанные payload/селектор сохраняются вместе.

| Поле | Что восстанавливает |
|---|---|
| Opacity | Собственную прозрачность поверхности |
| Brightness | Яркость |
| Gamma | Гамму |
| RGB color | Все три RGB-множителя |
| Feather | Local edge feather |
| Blend mode | Режим композиции |
| Visibility | Собственный enabled-флаг |
| Media / generator | Media UUID, procedural fallback и feedback output source вместе |
| Input UV | Input-рамку, source mesh и source Bézier lattice/transform |
| Output / mesh / parent | Output-рамку, regular/Bézier mesh и transform, projective weights, link-флаг и group UUID вместе |
| Shape / vertices / stroke | Тип формы, вершины треугольника и параметры пути |
| Masks / space / invert | Исходную polygon mask, её настройки и дополнительные scoped masks слоя |
| Key / FX | Настройки chroma/luma key и цветовых эффектов слоя |
| Material / parameters | Material UUID и overrides параметров вместе |
| Output routing | Output UUID либо All outputs |

Selective recall сохраняет текущие имена/UUID, порядок слоёв, новые и невыбранные поверхности, а также все исключённые поля. Удалённый target пропускается с предупреждением; Cue не создаёт его заново. Capture/Recapture требует текущих targets. Неиспользуемые resource references в исключённых полях могут оставаться dormant snapshot data; при включении такого поля его ссылки должны снова быть действительны. Невалидное объединение выбранных и текущих полей отклоняется целиком.

Выбранные числовые поля интерполируются линейно. Visibility, blend/source/routing, вершины треугольника и несовместимые геометрические/shape payload переключаются в середине; visibility-only Cue не меняет opacity. Input/output quads и совместимые пути интерполируются, если промежуточная геометрия допустима; при схлопывании используется соответствующее допустимое endpoint-состояние. Разные parent frames переключаются вместе с output/mesh. Нулевая длительность применяет конечные значения при обработке recall. Новая команда GO начинает переход от фактического текущего состояния. Редактирование и Undo прерывают fade, сохраняя промежуточное изменение в истории.

Full recall сохраняет прежнее поведение surface snapshot: восстанавливает сохранённые поля и порядок, скрывает более поздние поверхности, сохраняя их определения и automation bindings. Оба режима используют текущие общие определения групп; pose/opacity/visibility группы не захватываются. Dissolve запекает поддерживаемые изменения в текущие слои и применимые Cue fields; неоднозначные изменения appearance или конфликт с opacity automation отклоняются с пояснением.

Recall сам по себе не останавливает и не перематывает media/show clocks. Fades идут по host clock даже при Pause параметрического timeline. Активная timeline automation продолжает перекрывать соответствующие базовые поля Cue; её Pause/loop/seek/end остаются отдельными transport-событиями. Это не frame lock между декодерами. Undo возвращает сохранённое состояние документа до GO. Delete удаляет связанные Scene markers и tracks, потерявшие последний target в текущих поверхностях или оставшихся full snapshots.

Версии 0…5 мигрируют как full surface snapshots. Версии начиная с v6 сохраняют selective bindings. Cue-owned timelines, quantized launch и calendar scheduler остаются следующими этапами. Журнал ручных проверок selective workflow: [checklist](verification/selective-workflow.md).

### Графический Parameter Timeline

**Timeline…** открывает отдельное окно дорожек, графика и master show transport. Дорожка привязывается к существующей surface и одному из шести параметров: opacity, brightness, gamma, red, green, blue. Выберите Surface/Parameter → **Add track**. Один параметр одной surface имеет одну дорожку; повторное добавление выбирает существующую. Список включает отключённые и временно отсутствующие в текущей сцене targets. **Disable/Enable track** возвращает/включает override базового параметра; **Delete track** поддерживает Undo/Redo.

Выберите дорожку. Double-click графика добавляет ключ; drag ромба меняет time/value одним Undo-командой после отпускания мыши. **Time s**, **Value** и **Save key** задают точные значения. **Delete key** удаляет выбранный ключ; последний ключ удаляется вместе с дорожкой. Времена строго возрастают, не совпадают и лежат внутри Duration; opacity 0…1, gamma 0.01…10, остальные 0…16. Невалидная операция отклоняется целиком. **View/Fit/＋/−** меняют видимый диапазон времени; остальные параметры, кроме opacity, имеют автоматически подобранный диапазон значений.

Interpolation относится к сегменту **после** выбранного ключа: **Hold** удерживает значение до следующего ключа, **Linear** даёт прямую, **Bezier** использует normalized C1/C2. Оранжевые ручки редактируются на графике или численно. Control x/y лежат в 0…1, C1.x ≤ C2.x: временная кривая остаётся монотонной, а значение не выходит за диапазон концов. На flat сегменте касательные не меняют постоянное значение. Значение в точном времени ключа равно этому ключу. За крайними ключами удерживается крайнее значение. Auto Curve ещё не добавлен; запись inspector input описана ниже.

**Play/Pause/Stop**, числовой **Seek** и drag линейки управляют собственным show clock; загруженное видео для этого не требуется. Нижняя панель основного редактора и OSC/MIDI transport управляют теми же часами. **Duration / graph end** задаёт горизонт ключей/маркеров. **Stop at duration** включён в новых проектах: play останавливается в конце; повторный Play начинает с начала. При выключенном Stop время может продолжаться за графиком (до 365 суток), а последние значения ключей удерживаются; typed Seek также разрешён за горизонтом. Проекты v0–v4 мигрируют в этот continue mode, чтобы прежние длинные/looping видео не обрывались через 10 секунд. В новых проектах исходный горизонт — 10 секунд. Установите нужную Duration явно; её сокращение не удаляет находящиеся дальше ключи/маркеры, а отклоняется.

**Loop range** повторяет [Start,End) с сохранением остатка времени при переходе границы; loop имеет приоритет над Stop at duration. При смене позиции/loop/конце master синхронизирует media transport; каждый movie затем применяет собственный loop/clamp по длительности источника. Это не frame lock между декодерами. Вычисление параметров и доставка маркеров выполняются timer tick около 30 Hz с monotonic host time; графическое окно отображает тот же playhead. Seek не генерирует marker events.

**Add marker at playhead** добавляет **Pause** или **Recall scene**. Маркеры должны иметь разные положительные времена внутри Duration; для добавления сначала перейдите к нужному времени. Pause останавливает часы точно на marker time; следующий Play продолжает без повторной остановки на нём. Recall scene вызывает существующую surface scene. Marker срабатывает при естественном проходе `(previous,current]`; seek/попадание ровно в marker time не запускает его. Marker в Loop End проходит перед wrap; marker в Loop Start может пройти в начальном preroll, но не запускается повторно от одного приземления при wrap. **Seek marker** только перемещает playhead. Удаление сцены удаляет её marker references одной Undo-командой.

При длинной задержке обрабатывается не более 256 событий/переходов loop за tick; excess cue events пропускаются с видимой диагностикой, однако первая Pause сохраняется. Изменение дорожек/настроек сохраняет уже естественно пройденные events для однократной доставки; Stop/Seek очищают очередь. Существующие scene fades используют собственный host clock и могут продолжаться, когда parameter timeline поставлен на Pause. Совместная графическая audio/MIDI/OSC montage, внешние clock/timecode, Conductor banks и schedule остаются следующими областями реализации. `Demo/Timeline.aperturecue.json` — собственный параметрический пример.

### Запись scalar automation из inspector

Сначала создайте нужную дорожку через **Add track**. Выберите её и нажмите **Arm selected**; можно подготовить несколько дорожек. Arm разрешён только enabled track текущей поверхности: dormant target из full snapshot для записи не подходит. **Disarm selected** и **Disarm all** снимают подготовку. Arm и режим записи существуют только в текущем сеансе, сами не меняют документ и не сохраняются в JSON. New/Open очищает Arm; удалённые, отключённые дорожки и отсутствующие текущие targets исключаются из него.

Нажмите **Play** внутри **Duration / graph end**, затем **Record input**. В основном inspector двигайте Opacity, Brightness, Gamma, Red, Green или Blue выбранной поверхности. Записывается только её соответствующая enabled/armed дорожка; новые tracks автоматически не создаются. В режиме записи эти slider показывают вычисленное текущее значение и полный допустимый диапазон параметра. Другие sliders и обычные правки документа завершают режим записи перед своей операцией. Это запись изменений этих шести inspector controls: таймер, OSC/MIDI, камера, media/audio и montage не записываются.

Один жест начинается с вычисленного значения дорожки в момент нажатия. Continuous изменения создают linear keys во времени show clock; при обычном отпускании последний принятый value удерживается до момента отпускания. После отпускания режим остаётся включённым для следующего жеста. Каждый изменённый жест — одна Undo-команда, а не вся сессия Record input. Нажатие без изменения value не создаёт команду. Принятые keys сразу входят в документ: они видимы сохранению/recovery даже до завершения жеста. Текущий записываемый параметр применяется к output немедленно; изменение базового surface value для этого не требуется.

Запись заменяет старые keys внутри включённого диапазона `[начало жеста, последний принятый sample]`. Keys снаружи сохраняют свои time/value/interpolation/handles; соседние сегменты могут изменить кривую из-за новых соседей. Записанный участок линейный, его затем можно редактировать обычными средствами графика. Времена одного жеста не убывают; совпавшее время заменяется последним value. Лимиты: до 4096 samples одного жеста и 4096 keys одной дорожки, до 65536 keys проекта. Невалидный sample или превышение бюджета останавливает запись атомарно, сохраняя ранее принятый участок.

**Stop recording**, Pause/Stop/Seek, loop wrap, Scene GO, конец graph duration и редактирование документа завершают режим. При таком прерывании сохраняется только последний принятый участок; искусственный endpoint в момент остановки не добавляется. Запоздалые события старого gesture после прерывания не превращаются в новую правку поверхности. Arm можно оставить для следующего запуска Record input. Старт записи фиксирует активный scene fade; изменение Arm также завершает запись. Save/Undo/Redo завершают текущий жест перед своей операцией.

Запись использует обычные keys и сохраняет текущую позицию и playback при правке keys и Undo/Redo. Pause, Seek, loop и end выполняют собственные transport-действия. Arm и режим записи действуют до закрытия проекта.

## LED mapping и симулятор

**LED…** добавляет линейную fixture по количеству pixels, universe, начальному DMX address и двум нормализованным точкам композиции. Выберите RGB, GRB или RGBW. **Add fixture + simulate** сохраняет layout в проекте и открывает симулятор, не включая отправку в сеть. Адреса каналов начинаются с 1; universe передаётся на провод без автоматического смещения. Fixture не переносится через границу 512 и не перекрывает занятые каналы. Поэтому для RGB при address 1 доступно до 170 pixels, для RGBW — до 128.

Sampling берётся из полной output composition, уменьшенной до 320×180, nearest pixel, с частотой не выше 30 Hz. При занятости GPU/sender кадры пропускаются вместо накопления очереди. Это не фильтрация по площади fixture и не физическая калибровка LED. Симулятор показывает первые raw RGB channel triplets universes; он не декодирует обратно произвольный GRB/RGBW профиль в реальные цвета приборов.

Для отправки задайте числовой IPv4 destination, выберите Art-Net или sACN и нажмите **Start network output**. Порты: Art-Net source/destination 6454, sACN destination 5568. По умолчанию target `127.0.0.1`; отправка включается только явно. При смене target/protocol сначала завершается прежний output, затем применяются новые проверенные settings. **Stop output** останавливает sampling и передаёт нулевые ArtDmx levels либо обычный zero-valued sACN data packet, за которым следуют три packets с Stream Terminated. Это разные действия: receiver игнорирует channel values в terminated packet. **Clear fixtures** сначала останавливает output, затем удаляет layout. Runtime target/protocol не являются сохранёнными полями проекта.

Quit ставит media на паузу, останавливает controls и дожидается очереди lighting Stop с ограничением около одной секунды. Это попытка корректного завершения локальной отправки, а не подтверждение, что UDP packet получен реальным node.

Этот этап поддерживает простые strips и UDP data packets. Полный fixture-definition editor, 16-bit channels, moving lights, protocol discovery/sync, USB-DMX и recorder ещё не закончены. Физическое поведение реального node при blackout/termination требует отдельной проверки. Симулятор и localhost loopback не дают аппаратной совместимости или полной protocol conformance; OEM registration для Art-Net остаётся незавершённой.

## Сохранение, история и экспорт

**File → Save** (`⌘S`) и **Save As** (`⌘⇧S`) записывают `.aperturecue.json`, **Open** (`⌘O`) открывает его. Текущий формат — schema 12: он сохраняет Bézier/source warps, mesh link, projective/isolation groups, дополнительные masks, FX, material library и assignments, feedback и output edge blend. Старые проекты мигрируют; alpha 14 и более ранние сборки новые файлы не открывают. Перед первым Save используйте **Save As…**, чтобы оставить исходник для старой версии. Маршруты из проектов v0–v9 сохраняются, дисплеи для fullscreen выбираются заново. Пути к обычным медиа на диске относительные.

File → **Collect portable project…** создаёт переносимую копию в новой, ещё не существующей папке. Внутри находятся `project.aperturecue.json`, обычные ресурсы `media/<asset UUID>.<extension>` и отдельные UUID-папки с точными frozen manifests кадров. Такое именование разделяет одноимённые источники. Приложение копирует обычные image/video/audio files и только перечисленные sequence frames, проверяет созданный проект и относительные ссылки, затем публикует готовую папку одним переименованием. Missing media, неподходящий source или ошибка копирования отменяют операцию; исходный проект и выбранная папка назначения не перезаписываются.

Collect работает в фоне со снимком текущего проекта. Открытый документ не переключается на копию; более поздние правки не входят в уже начатый сбор. Live camera IDs сохраняются как ссылки на устройства и на другом компьютере могут быть недоступны. Для переноса откройте `project.aperturecue.json` из собранной папки и перемещайте её целиком.

Undo (`⌘Z`) и Redo (`⇧⌘Z`) работают с правками документа. Drag записывается одной операцией. История ограничена 100 снимками, очищается при New/Open и не сериализуется между запусками. Действия внешних устройств и текущее время плеера не являются document undo.

Для изменённого проекта с уже выбранным именем каждые примерно 10 секунд записывается отдельный recovery file `.<project filename>.recovery`, привязанный к точным байтам/пути/mtime сохранённой revision. Restore предлагается только для актуального bound checkpoint и повторно проверяет его перед загрузкой. Устаревший, повреждённый, legacy или чужой sidecar сохраняется с диагностикой. Успешный Save и явный Discard удаляют только собственный checkpoint. Автоматическая separate-process SIGKILL/restart проверка записана в status; power loss и повреждение файловой системы не проверены.

File → Export PNG… (`⌘E`) сохраняет композицию кадра 1920×1080 без handles. Это still export, а не экспорт timeline/movie или standalone show.

## Диагностика

Нижняя строка показывает renderer FPS, время CPU encode, GPU command time, skipped submissions и сообщения media errors. Эти числа не являются процентом загрузки CPU/GPU или точным счётчиком dropped video frames.

Команды диагностики из корня проекта:

```sh
dist/ApertureCue.app/Contents/MacOS/ApertureCue --self-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --composition-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --editor-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --source-editor-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --media-playback-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --audio-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --durability-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --media-soak-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --protocol-loopback
dist/ApertureCue.app/Contents/MacOS/ApertureCue --lighting-test
dist/ApertureCue.app/Contents/MacOS/ApertureCue --benchmark
```

`--self-test` создаёт `artifacts/local/self-test.json`: production Metal и короткий собственный H.264 clip. `--composition-test` записывает `artifacts/local/composition-test.json` для materials/ISF, key/FX, isolation, scoped masks, edge blend, warp/source sampling и предыдущего поколения feedback. `--editor-test` проверяет настоящие document/control callbacks, историю и сохранение, записывая `artifacts/local/editor-test/report.json`. Успех hidden callbacks отдельно от ручной работы в видимом окне. `--protocol-loopback` проверяет локальную UDP доставку OSC и MIDI parser. `--lighting-test` создаёт `artifacts/local/lighting-test.json`: полный GPU → sampling → production sender → настоящий localhost UDP → decoder, включая color order, automation, routing, blackout и simulation без network. `--benchmark` создаёт `artifacts/local/live-benchmark.json` с короткой серией visible drawable submissions.

`--source-editor-test` проверяет production Sources callbacks; `--media-playback-test` — source PTS/cache и camera simulator; `--audio-test` — actual-engine offline PCM без hardware output; `--durability-test` — separate-process SIGKILL/restart на собственных временных документах. `--media-soak-test` добавляет 120-секундный четырёхисточниковый прогон с PTS/drift/missing-pull статистикой. Отчёты находятся в одноимённых подпапках `artifacts/local`.

Фактические результаты каждой серии указаны в [status.md](status.md); сохранённые отчёты — в [verification](verification). Ни один короткий тест не подтверждает длительный show, оптическую частоту проектора, внешний дисплей, физическую fixture или захват конкретной камеры. В benchmark нет video decoding.
