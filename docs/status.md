# Текущее состояние ApertureCue

Обновлено: 27 октября 2026 (Europe/Moscow), macOS first. Исследование начато 25 октября. Полное функциональное равенство MadMapper **не достигнуто**. Задача продолжается по [roadmap](roadmap.md); [матрица](feature-matrix.md) различает исследование, реализацию, автоматические, ручные и аппаратные проверки.

## Окружение и референс

- macOS 26.6.2 build 25G83, MacBook Air M2, GPU Apple M2 10 cores, 8 GiB RAM, arm64.
- Apple Swift 6.3.3 / Apple clang 21, Command Line Tools; Qt, CMake и FFmpeg не установлены. Нативная сборка не загружает внешние зависимости.
- Установлен MadMapper **Demo 6.0.5**, bundle build `6.0.5.25122226043`. GUI доступен. В отдельном новом тестовом Video-проекте проверены пустой список поверхностей и создание группы. В Demo пункты Open/Save/Collect/Export отключены. Подробности O01–O04 в [research](research.md).
- Публичные материалы исследованы для ветки MadMapper 6: 44 источника, 84 строки каталога. Это широкий первоначальный каталог, не доказанный исчерпывающий перечень всех меню и параметров конкретной patch-версии.
- [Исходники опубликованы](https://github.com/aborokhvostov/ApertureCue), [prerelease alpha 6](https://github.com/aborokhvostov/ApertureCue/releases/tag/v0.1.0-alpha.6) опубликован для `99ea8de94ff26b88622a2d5492acd3ec000580f7`. [ZIP и проверка архива](verification/distribution.md); alpha 1/2/3/4/5 сохранены в истории. Исходный локальный репозиторий был пуст, remote отсутствовал. Поиск точного `ApertureCue` в web и GitHub не дал совпадений; это не юридическая проверка товарного знака.
- Внешние проекторы/свет/MIDI hardware не подтверждены. Camera adapter проверен по отказу, захват реального устройства не проверен. Локальный графический сеанс может использовать виртуальный дисплей.

## Реализованный работающий subset

AppKit editor, Metal compositor, PNG/images и AVFoundation video, textured line/Bézier paths, quad/triangle/ellipse в четырёхугольной перспективной рамке, independent input/output, projective homography, regular mesh, source-UV polygon mask, local shape feather и antialias, normal/add/multiply/screen, brightness/gamma/RGB, layer ordering, UUID group hierarchy с affine/shear и inherited per-layer opacity/visibility, undo/redo, schema v6 JSON с v0/v1 quad и v0–v2 legacy-group migration, relative media paths, atomic save, named-project recovery, missing-media fallback и relink.

Отдельные output windows с display selection/routing/blackout; full/selective surface snapshots with 13 atomic field masks and a native Scenes editor; графический parameter timeline с Hold/Linear/Bezier, independent show clock, loop/continuation и Pause/Scene markers; latest-frame AVCapture adapter; fixed MIDI input profile, OSC localhost control с bounded main-thread mailbox; basic RGB/GRB/RGBW strips, asynchronous composition sampling, simulator и opt-in IPv4 ArtDmx/sACN. OBJ импортируется как статическая pinhole-проекция в editable quad patches, без depth buffer и сохранения исходной 3D-сцены. PNG still export.

## Текущий этап

Local checks passed: 74 standalone core methods, 46 GPU/media, 36 editor and 11 lighting/UDP. GUI capture/mask-save/recapture/GO/Undo/save/relaunch/reopen and the final window layout passed; fresh archive extraction/signature and all 36 editor checks from the ZIP passed; exact-source CI is being completed. Recorded automation and montage remain next; reference parity has not been reached.

SwiftPM локально не линкует `PackageDescription` из-за несогласованного установленного toolchain. `scripts/build.sh` собирает те же source напрямую `swiftc`, app и собственную dylib подписывает ad hoc. Это реальный обход сбойного build frontend, без изменения системного toolchain. Notarization и universal binary не выполнены.

Portable Collect проверен отдельными core tests: проект открывается с копиями после удаления оригиналов, дублирующиеся имена не конфликтуют, missing media откатывает только собственную staging folder, существующая destination не перезаписывается, camera IDs сохраняются. ZIP включает приложение, исходно сгенерированный demo, LICENSE и notices. Упаковка выполняется в системной временной папке без File Provider/AppleDouble metadata.

## Незавершённое

Базовый desktop workflow проверен автоматически и через GUI на текущем дисплее. Открыты: длительный soak, точный multi-source timing/PTS/drift, стабильные display IDs/hotplug, внешние проекторы; recorded automation/media/audio/MIDI/OSC montage/Conductor, free vertices/freehand/Bézier mesh/masks, group perspective/isolation/FX/automation, полноценный edge blending, audio engine/routing/analysis, расширенные fixtures/recording, external SDK adapters, live 3D/calibration/scanner, offline video/light export и standalone player, Windows/Linux desktop.

Alpha 6 опубликован после успешного CI, проверки подписи и 29 редакторских проверок из распакованного ZIP. ZIP и SHA256SUMS загружены; digest GitHub совпал с локальным архивом. Следующий инженерный этап — recorded automation/media montage; group perspective/isolation/FX/automation и Conductor/external clock остаются открытыми. Отсутствие оборудования удерживает H gates открытыми; это не мешает программной реализации и не означает аппаратной совместимости.

Selective editor checks use real hidden control callbacks and production document methods: per-surface UUID masks, Save vs Recapture, hidden/current-order/new-layer preservation, Undo/Redo, missing-only clean no-op, orphan full-cue track/marker cleanup and source-excluding GO during an actually decoded original H.264 movie. Remote XCTest remains a separate gate.
